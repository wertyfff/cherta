# ЧЕРТА. — ремонт, в котором всё под контролем

Концепт-лендинг вымышленной компании по ремонту квартир. Главная идея — цифровой «Паспорт ремонта»: смета, этапы, фото, материалы и изменения на одной странице.

**Сайт:** https://wertyfff.github.io/cherta/

- Статика без сборки: `index.html`, `styles.css`, `script.js`
- Анимации — GSAP + ScrollTrigger, плавная прокрутка — Lenis
- `?static` в адресе отключает прелоадер и анимации (для скриншотов)

Компания, объекты и данные вымышленные. Фото — Unsplash.
